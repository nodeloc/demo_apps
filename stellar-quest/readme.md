# 星球探索

用社区能量驱动的宇宙收集游戏：探索星域、发现天体、集齐图鉴、升级飞船，去更远的地方。

## 玩法

- **探索**消耗燃料（初始星域 20 / 深空 50 / 虫洞 100）。每次探索发现一个天体，或遇到一个需要抉择的未知事件。
- **图鉴**收录 40 种天体（普通 20 / 稀有 12 / 史诗 6 / 传说 2）。重复发现转化为星尘（1 / 5 / 20 / 100）。
- **星尘 + 燃料**升级飞船（Lv.1–5），解锁深空与虫洞。
- 稀有及以上天体记录**全服首位发现者**。排行榜按探索者（每周）、收藏家、发现者三项各自计。

## 能量与游戏的边界

游戏内从不直接扣能量。唯一的能量出口是**补给站**：⚡100 换 🛢100 燃料，
每一笔都经过站点自己出示的付款确认框——玩家亲手确认，能量才会离开。
游戏不返还能量、不提现、不转账；产出只有图鉴、星尘与荣誉。

新探索者赠送 60 燃料。发货按 request_id 幂等，`api.points.spends()` 对账保证
「确认过的补给绝不丢失」。

## 服务端权威

发现什么、扣多少燃料、谁是首发现——全部由 handler 在服务端沙箱内决定。
页面只负责星空与动画；未发现天体的名字与描述不会出现在客户端。
